A one-star review written by a house cat about its human: the cat locks horns with the bedroom door, holds a concert for it until 3 a.m., and awards the door five stars. One line, deadpan, under 200 characters — built for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty.

## Run it

```sh
python3 main.py
```

Writes the review to `/output/entry.txt`.
